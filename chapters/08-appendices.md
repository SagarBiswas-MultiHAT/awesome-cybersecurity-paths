<a id="appendix-d-glossary-of-key-terms"></a>
# **Appendix D: Glossary of Key Terms**

The following definitions provide quick reference for technical and professional terms used throughout this handbook.

<div align="center">

| **Term** | **Definition** |
| --- | --- |
| APT (Advanced Persistent Threat) | A sophisticated, prolonged cyber attack typically conducted by nation-state actors with specific strategic objectives and extended dwell time in the victim environment |
| Attack Surface | The complete set of points in a system or environment where an attacker could attempt unauthorized entry, data extraction, or service disruption |
| Blue Team | The defensive security team responsible for protecting systems, detecting attacks, and responding to and recovering from incidents |
| C2 (Command and Control) | Infrastructure used by attackers to communicate with and issue commands to compromised systems; also called C&C |
| CVE (Common Vulnerabilities and Exposures) | Standardized unique identifiers assigned to publicly disclosed security vulnerabilities, maintained by MITRE |
| CVSS (Common Vulnerability Scoring System) | A numerical scoring system (0.0-10.0) for expressing the severity of security vulnerabilities based on exploitability and impact |
| Defense-in-Depth | A layered security strategy ensuring that the failure of any single control does not result in complete system compromise |
| Dwell Time | The period of time an attacker remains active inside a compromised environment before detection; lower is better for defenders |
| EDR (Endpoint Detection and Response) | Security software providing continuous monitoring, behavioral detection, investigation capability, and remote response for endpoint devices |
| GRC (Governance, Risk, and Compliance) | The integrated framework for managing cybersecurity policy, risk quantification and treatment, and regulatory obligation adherence |
| IOC (Indicator of Compromise) | Digital artifacts such as file hashes, IP addresses, domain names, or registry keys indicating that a system has been compromised or attacked |
| ISAC (Information Sharing and Analysis Center) | Sector-specific organizations facilitating threat intelligence sharing between organizations in critical infrastructure industries |
| Lateral Movement | Techniques used by attackers to progressively move through a network from an initial foothold toward their ultimate target |
| Living-off-the-Land (LotL) | Attack technique using legitimate built-in operating system tools (PowerShell, WMI, certutil) to perform malicious actions, blending into normal administrative activity |
| MITRE ATT&CK | A globally accessible knowledge base of adversary tactics and techniques based on real-world observations, used for threat modeling and detection planning |
| Pen Test (Penetration Test) | An authorized, structured simulation of a cyber attack on a specific system or network to identify exploitable vulnerabilities |
| PKI (Public Key Infrastructure) | A system for issuing, managing, distributing, and revoking digital certificates that establish and verify identity in digital communications |
| Privilege Escalation | Exploiting a vulnerability or misconfiguration to obtain higher-level access than was originally granted |
| Purple Team | A collaborative security model where offensive (red) and defensive (blue) teams work together in real time to identify gaps and improve detection and response capabilities |
| RCE (Remote Code Execution) | A vulnerability class allowing an attacker to execute arbitrary code on a target system from a remote location without physical access |
| Red Team | An authorized offensive security team that simulates real-world threat actors using stealth and advanced techniques to test an organization's detection and response capabilities |
| SIEM (Security Information and Event Management) | A platform aggregating and correlating security event data from across an environment to enable threat detection, investigation, and compliance reporting |
| Social Engineering | Psychological manipulation of people into performing security-relevant actions or disclosing confidential information, bypassing technical controls by targeting human behavior |
| SOAR (Security Orchestration, Automation, and Response) | Platforms that automate repetitive security tasks and orchestrate workflows across multiple security tools to accelerate incident response |
| TTP (Tactics, Techniques, and Procedures) | The patterns of behavior and specific methods used by a threat actor during an attack; the foundational vocabulary of threat intelligence and detection engineering |
| Zero-Day | A software vulnerability unknown to the vendor and for which no patch exists; exploits targeting zero-days are particularly dangerous as no immediate mitigation is available |

</div>
